## 受入条件

実装済みは本番品質の承認を意味しない。npm test、npm run check、npm run build、npm pack、ランチャーの旧/v2ブラウザ試験、実Vue3、全スタジオ、独自HTML、配布版、スマホ/キーボードを確認すること。詳細はTEST_REPORT_V2.md。

## 制約と後続改善

グリッド仮想化は読み取り専用で、複数ページに跨る範囲編集やサーバー側ページングは未対応。リッチテキストは簡易装飾・プレーンテキスト出力。画面生成はUIのみ、2列レイアウト。デバイス幅の模擬であり実機エミュレーションではない。アクセシビリティ・実機・本番負荷の認証、TypeScript宣言、単一bundle/minify、公開npm登録は別工程。野獣大富豪には導入しない。
