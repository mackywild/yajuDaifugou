## 対応

| ID | 修正内容 |
|---|---|
| RV-08 | 操作可否とデータ検証を分離。readonly/disabledを含む全送信値の必須・範囲・独自検証、ロックされたネイティブ入力の検証補完、エラー表示保持、編集不能項目のエラーフォーカス。検証済み送信スナップショットをonSubmitへ渡す。 |
| RV-09 | 表示座標と確定値を分離。共通のresolveRangeで表示中の行ID・列keyと最新ストアを照合。コピー、貼り付け、セル削除に使用。行が消失した場合は拒否。遅延再描画を維持し、既存の安全TSV、行選択・履歴を変更しない。 |

## 仕様判断・制約

- 個別disabled/readonlyもgetValues/onSubmitに含める既存契約を維持し、その全値を検証する。以前は個別ロック項目の検証が免除されていたが、誤送信防止のため変更。サーバー側の認可・検証は引き続き必須。
- 遅延描画中の範囲操作は表示中の座標に対応するIDを基準とし、未描画の新しいソート順には切り替えない。値のみ確定済みストアを使用する。再描画後は既存の選択復元規則。
- 実Node/npmコマンド、実ブラウザ/実Vue/IME/Excel、生成HTML/SFCの実行、配布パッケージの別アプリ導入は未実施。コンテナでgit ls-remoteを再試行したがgithub.comのDNS解決に失敗した。隔離・スタブ合格は実機合格と区別する。
