# Daifugo v0.2.0 野獣ルール仕様

## 1. 野獣対象化
プレイヤーの手札に **8を1枚以上** かつ **10を1枚以上** 所持した時点で、野獣ルール対象となる。

対象化タイミングは次の2つ。

1. ゲーム開始時の配牌直後
2. 7渡しでカードを受け取った直後

一度対象になったプレイヤーは、そのゲーム中に野獣ルールを解除できない。

対象化した事実は全プレイヤー共有情報とし、`YAJU_AVAILABLE` イベントを全端末へ配信する。
Androidアプリはこのイベントを受信すると `yaju_available` 音声を再生する。

## 2. 8・10保持義務
野獣対象者は通常進行中、手札に8と10を最低1枚ずつ残さなければならない。

- 8が1枚しかない場合、その8は通常プレイや7渡しで消費できない
- 10が1枚しかない場合、その10は通常プレイや7渡しで消費できない
- 8または10を2枚以上持っている場合、最低1枚を残せば余剰分は使用可能

例:

- `8×1 / 10×1` → どちらも7渡し不可
- `8×2 / 10×1` → 8を1枚だけ7渡し可能
- `8×2 / 10×2` → 8を1枚・10を1枚まで手放しても対象状態は維持

## 3. 7渡し
7を含むプレイが成立した場合、出した7の枚数だけカードを時計回りの次の未上がりプレイヤーへ渡す。

ただし、実際に渡せるカード枚数が7の枚数より少ない場合は、合法的に渡せる枚数までに制限する。
これは野獣対象者が最後の8/10を渡してルールを手放すデッドロックを防ぐため。

7渡し中は通常のカード提出・パスを実行できない。
7渡しが完了してから次のターンへ進む。

受け手が7渡し後に8と10を揃えた場合、その場で新たな野獣対象者となる。

## 4. 野獣上がり
野獣対象者は最後の2枚を **8 → 10** の順番で、それぞれ単体で出して上がる。

### 第1段階
手札がちょうど `8×1 / 10×1` の2枚になった状態で8を単体提出する。

8切りが発動するため、場が流れて本人が再び親になる。
状態は `EIGHT_PLAYED` へ移行する。

### 第2段階
残った10を単体提出して上がる。

状態は `COMPLETED` となり、`YAJU_SUCCESS` イベントを全端末へ配信する。
Androidアプリは `yaju_success` 音声を再生する。

## 5. 違反上がり
野獣対象者が8→10の正規手順を経ずに手札を0枚にした場合、禁止上がりと同様に反則上がりとして扱う。

- プレイ自体は成立する
- 野獣状態は `PENALTY`
- 空いている最下位順位を割り当てる

通常進行中に最後の8または10を消費しようとした場合は、上がりではないためプレイを拒否する。

## 6. 全体共有情報
次の情報は秘密情報ではなく全プレイヤーに公開する。

- 各プレイヤーが野獣対象か
- 野獣状態 (`ACTIVE`, `EIGHT_PLAYED`, `COMPLETED`, `PENALTY`)
- 新規対象化イベント
- 野獣上がり成功イベント
- 7渡しの実行者、受け手、必要枚数

手札そのものは従来通り本人以外へ公開しない。
