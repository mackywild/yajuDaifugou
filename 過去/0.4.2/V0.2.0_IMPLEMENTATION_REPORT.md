# Daifugo v0.2.0 野獣ルール実装レポート

## 実装内容

### Game Core
- `YajuStatus` を追加
- 配牌時の8+10判定
- 7渡し受領後の8+10判定
- 一度対象になった野獣状態の解除禁止
- 最低1枚の8/10保持義務
- 余剰8/10の通常利用・7渡し許可
- 最後の2枚 `8 → 10` による野獣上がり
- 順序違反上がりを反則最下位として処理
- `YAJU_AVAILABLE` / `YAJU_SUCCESS` 全体共有イベント

### 7渡し
- 7の提出枚数に応じた譲渡保留
- 次の未上がりプレイヤーを譲渡先として選択
- 7渡し完了までplay/passをロック
- 野獣対象者の最後の8/10譲渡を拒否
- 余剰8/10を隣へ押し付け可能
- 受け手が8+10を揃えた場合に野獣対象を伝播
- 7渡し後のターン進行・場流しを継続

### API / Response
- `POST /api/rooms/{roomId}/seven-transfer`
- `sevenTransfer` 状態をGameStateResponseへ追加
- `events` をGameStateResponseへ追加
- `PlayerResponse.yajuStatus` を追加

### Android
- 7渡し選択UI
- 野獣対象者表示
- 全体共有イベントの重複防止
- 差し替え式音声再生
- `yaju_available` / `yaju_success` を動的検索するため、音声未配置でもビルド・動作可能
