# Daifugo v0.1.0 実装・検証レポート

## 実装範囲

### Android
- Kotlin + Jetpack Compose
- versionName `0.1.0` / versionCode `1`
- Login / Lobby / Room / Game / Result
- サーバーURL指定
- 共通パスワード認証
- JSESSIONIDをメモリCookieJarで保持
- CSRFトークン対応
- 部屋作成 / 参加 / 退出
- ホスト開始
- 手札タップ複数選択
- カード提出 / パス
- 相手残枚数表示
- 場札 / 手番 / 革命 / マーク縛り / 順位表示
- WebSocket状態変更通知
- WebSocket断時5秒RESTフォールバック
- adaptive icon
- GitHub Actions APK build

### Server
- `spring-boot-starter-websocket`
- `/ws/game?roomId=...`
- WebSocketは通知専用。ゲーム操作は受け付けない
- HTTPセッションの認証・roomId・playerId・部屋所属をHandshake後に検証
- create/join/start/play/pass/leave/logoutで `STATE_CHANGED` をbroadcast
- 各クライアントは通知後、自分のセッションで `/state` を取得するため手札秘匿を維持
