# v0.4.1 Implementation Report

## 目的

CPUの連続自動進行が速すぎて、人間がCPUの提出カードを認識できない問題を修正する。

## 実装

### LocalCpuGameManager

従来の `processCpuTurns()` による一括実行を廃止。
`hasCpuTurn()` と `executeNextCpuTurn()` を追加し、CPUを1手ずつ進行する。
実行結果にはCPU名・PLAY/PASS/7渡し・対象カード・7渡し先・実行後GameStateを含める。

### DaifugoViewModel

CPU手番専用Coroutineを追加。
PLAYは3,000ms、PASSは1,500ms、7渡しは2,000msの表示時間を確保してからGameStateを画面へ反映する。

### Compose UI

- THINKING表示
- CPUカード提出アニメーション
- PASS表示
- 7渡し表示
- CPU行動履歴（直近4件）

## 回帰方針

CPUのルール判断は既存GameEngine/CPU Strategyへ委譲したままのため、演出実装はルール判定へ介入しない。
