# Daifugo v0.4.2 Implementation Report

## 目的

v0.4.2では、対戦画面の「開発中UI感」を減らし、市販カードゲームアプリのようにプレイ状況を直感的に把握できるUIへ刷新した。

## 実装内容

### 1. プレイカード
- 四隅インデックス付きのオリジナルトランプデザインへ変更
- 白〜アイボリー基調、赤/黒スート、金アクセント
- Joker専用表示
- 選択時は金枠＋浮き上がり表現

### 2. 相手手札
- 「残りN枚」というテキスト主体の表示を廃止
- `handCount` と同じ枚数の裏向きカードを重ねて表示
- 枚数が多い場合は重なり幅を自動圧縮

### 3. 7渡し秘匿演出
- CPUの7渡しでは渡すカードを表向き表示しない
- UI状態にも7渡しカード内容を保持せず、`cardCount`だけを渡す
- 行動ログもカード名を残さず「N枚を○○へ7渡し」と表示

### 4. 野獣確定カットイン
- `YAJU_AVAILABLE` を受けると全画面カットイン
- 初期配牌時の野獣対象化、7渡しによる途中対象化の両方に対応
- 初期配牌で複数人同時対象になった場合は1回のカットインへまとめて表示
- カットイン表示中はCPU進行を一時停止

### 5. プレイヤーアイコン
- Compose Canvasで描画するオリジナルアイコンを8種用意
- 席順をキーとして割り当てるため、同一卓最大4人で重複しない
- ロビー、対戦画面、自分の手札、リザルトで同じアイコンを維持

### 6. 行動ログ
- CPU行動ログを直近4件から6件へ拡張
- PLAYは出したカードを表示
- PASSはPASS表示
- 7渡しはカード内容を秘匿し、枚数と受け手のみ表示
