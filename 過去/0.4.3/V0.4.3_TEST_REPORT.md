## 重点テスト

- `8,10` → `8` → `10` 野獣上がり
- `8,10,10` → `8` → `10,10` 野獣上がり
- 通常状態でJ提出後に低いランクが勝つ
- 革命状態でJ提出後に高いランクが勝つ
- 通常Jバック直後の単体3で早漏イベント
- 3のペアでは早漏イベントを出さない
- 次プレイヤーPASS後、次々プレイヤーの3では早漏にしない
- 革命+Jバックでは早漏判定を予約しない
- JバックOFF時はJを出してもJバックにならない
- 場流しでJバック/早漏状態を解除
- 野獣制約で拒否されたプレイが早漏判定権を誤消費しない
