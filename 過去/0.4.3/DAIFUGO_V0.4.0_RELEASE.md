# Daifugo v0.4.0 — CPU BATTLE UPDATE

## Highlight

一人用CPU戦 **【ひとりでイク】** を追加。

ログイン後のメインメニューから「マルチプレイ」または「【ひとりでイク】」を選択できるようになりました。

## CPU Battle

- CPU人数: 1〜3人
- 難易度: 簡単 / 普通 / 難しい / N-GOD
- 特殊ルールを対戦ごとに設定
- PC / Android / iPhone共通対応

## N-GOD

自己対戦5,000ゲーム、278,188局面から学習したニューラル評価CPU。

Hard CPU 3体との4,000ゲーム評価で:

```text
1位率    31.3%
平均順位 2.173
```

4難易度中トップを確認。

## Compatibility

既存のマルチプレイ、野獣ルール、Android/iOSクロスプレイを維持したまま追加しています。
