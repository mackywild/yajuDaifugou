# Daifugo v0.4.0 Test Report

## Summary

CPU BATTLE UPDATEの成果物化前に、ゲームコア・CPU思考・学習済みN-GOD・クライアント構文を再確認した。

## 1. Existing + CPU unit tests

Gradle distributionを外部取得できない環境のため、JUnit 5の使用APIとSpring annotationを互換スタブへ置き換えたネットワーク不要ランナーで、`src/test/java`のゲーム/ルーム/ログイン制限テストを実行した。

```text
RESULT pass=100 fail=0 total=100
```

v0.4.0で追加したCPUテストを含む。

- `CpuStrategyFactoryTest`
- `NgodNeuralModelTest`
- `LegalMoveGeneratorTest`
- `CpuGameServiceTest`

GitHub Actionsでは本物のJUnit 5 / Spring Boot環境で `./gradlew clean test` を実行する。

## 2. CPU feature smoke

```text
CPU_FEATURE_SMOKE_PASS
```

確認内容:

- 4難易度のStrategy生成
- N-GOD出力値が0〜1

## 3. N-GOD benchmark

各チャレンジャー1体 + Hard CPU 3体。座席をローテーションし4,000ゲームずつ実行。

```text
EASY   games=4000 winRate=0.053 avgRank=3.309 dead=0
NORMAL games=4000 winRate=0.230 avgRank=2.503 dead=0
HARD   games=4000 winRate=0.259 avgRank=2.485 dead=0
N-GOD  games=4000 winRate=0.313 avgRank=2.173 dead=0
```

難易度順序を1位率・平均順位の両方で確認。
