## 仕様テストのポイント

### 相手手札

`handCount`回 `CardBack` を描画するため、数字だけでなくカードの重なりから残枚数を視覚的に確認できる。

### 7渡し

CPUの7渡し時、UIへ渡す `CpuTurnAnimation.cards` は空リストとし、`cardCount`のみ保持する。
表示も `CardBack` のみ、ログも枚数のみとする。

### 野獣カットイン

`YAJU_AVAILABLE` の未処理イベントをまとめて `YajuCutIn` へ変換する。
初期配牌時に複数人が対象化しても1回のカットインで全員表示する。

### CPU進行

カットイン表示中は `startCpuTurnSequence()` が待機するため、CPU先手でも演出が裏で終わらない。

## 最終ビルドゲート

GitHub Actionsの `Build debug APK` が成功し、`Daifugo-v0.4.2-debug` がアップロードされることを最終リリース条件とする。
