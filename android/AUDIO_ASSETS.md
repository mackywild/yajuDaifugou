# 野獣大富豪 オーディオ素材

Android版は `android/app/src/main/res/raw/` に音源を置くと自動で有効になります。

## メニューBGM

ファイル名は `menu_bgm.mp3` または `menu_bgm.wav`。

- 約2分のループ素材を想定
- タイトル / メインメニュー / CPU設定 / チャレンジ設定 / マルチ接続 / ロビー / ミッション等で共通再生
- 画面遷移しても再生位置を維持
- GAME画面へ入ると停止
- 曲頭と曲末が自然につながるループ素材を推奨

## 既存音源

- `yaju_available.mp3`
- `yaju_success.mp3`
- `yaju_bgm.mp3`

音源ファイルが無くてもアプリは無音で動作します。ストア公開可能な権利の音源を使用してください。
