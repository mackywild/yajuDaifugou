Daifugo CPU Avatar Photos
=========================

CPU対戦で使用する写真を、このフォルダに置いてください。

必須ファイル名（最大7CPU）:
  cpu_01.jpg
  cpu_02.jpg
  cpu_03.jpg
  cpu_04.jpg
  cpu_05.jpg
  cpu_06.jpg
  cpu_07.jpg

対応:
  CPU 1 -> cpu_01.jpg
  CPU 2 -> cpu_02.jpg
  CPU 3 -> cpu_03.jpg
  CPU 4 -> cpu_04.jpg
  CPU 5 -> cpu_05.jpg
  CPU 6 -> cpu_06.jpg
  CPU 7 -> cpu_07.jpg

推奨:
  - JPEG (.jpg)
  - 512 x 512 px 前後の正方形
  - 顔を中央寄せ
  - 端末で正しい向きに見えるよう、回転を確定した画像
  - 7枚すべて別の人物/写真
  - 公開APKへ入れる場合は、位置情報など不要なEXIFメタデータを削除推奨

表示:
  - 円形アイコンとして中央トリミングされます。
  - 写真が存在しないCPUは、従来の生成アイコンへ自動フォールバックします。
  - 写真を入れた後はAPKを再ビルドしてください。

注意:
  - ファイル名は完全一致させてください。
  - 拡張子は .jpg 固定です。
  - CPUローカル対戦だけで写真を使います。通信対戦のプレイヤー表示には影響しません。
